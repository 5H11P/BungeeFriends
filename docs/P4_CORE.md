# P4 核心功能阶段总结

状态：配置与中英文语言补漏已接入并通过 JDK 8 全模块构建及有限自动测试；真实代理端行为尚未验收。

## 已实现

- 好友：请求时间和超时检查、待处理请求列表、私有备注、好友建立时间、批量移除及强制添加；好友列表提供悬浮详情、相对时间和可点击分页，屏蔽列表也提供可点击分页。`/block`、`/ignore` 沿用旧屏蔽数据，保留 `/friend ignore`。
- 状态：`/status` 支持在线、离开、忙碌和隐身；状态持久化到两种存储。离线、功能关闭和插件停用时取消状态提示任务；隐身玩家不会向好友发送上下线通知。
- 组队：邀请时间/人数上限、设置中的全员邀请/静音/私有、离线踢人、成员权限检查与整队关系事务；队长和成员分组列出，设置帮助和禁言提示已接入。队员离线时可按配置定时移除，重连取消任务；队长离线后的晋升/解散延迟可配置。`/pl` 是列表别名。离队后组队聊天不再向旧队伍发送。
- 聊天：`/ac`、`/achat` 及 `/chat` 频道切换；Staff 和 Admin 频道在切换、发送和接收时校验权限。隐身状态下的私聊发送/接收按离线策略处理。
- 传送：手动 `/party warp` 与队长切服跟随使用可取消任务。执行前复核队长、成员、目标服、服务器过滤和插件状态；重复启动会取消旧任务，配置重载及停机取消挂起任务。可按游戏服务器成员快照二次确认，核心侧投递 `PartyWarpEvent`。
- 资源：核心打包配置只内置中英文；`available.yml` 仅列出中英文，旧语言选择回退英文。新增配置默认值在启动和重载时补齐，旧键迁移时优先保留新键已有值；非法整数回退默认值。已有自定义语言文件中的旧消息键可在缺少新键时回退读取。保留 `Main`、包名及 `BungeeFriends.getAPI()` 调用入口。
- 其他配置：好友删除通知可关闭；好友列表时间格式可配置；LuckPerms 离线前缀加载改用有界后台池，缓存时长与加载超时可配置。

## 接口约定

原有 `BungeeFriends.getAPI().getFriendUtils(UUID)` 和 `getPartyUtils(UUID)` 继续返回原工具对象；它们对未知 UUID 可创建数据，对未启用组队功能的调用不保证可用。存储读写是同步操作，SQL 失败以 `IllegalStateException` 传播；调用者不能把失败当作空列表。公开工具对象可能访问在线玩家和代理状态，宿主插件应在 Bungee 允许访问玩家状态的上下文调用，不应从 Bukkit 主线程跨端直接调用。跨端公开 API 属 P5 范围。

`PartyWarpEvent` 是一次已排定传送的代理端事件，包含独立 warp ID、队长、目标服、触发来源和不可修改的成员快照。事件经有界异步池投递；监听器不得假设调用发生在 Bukkit 主线程，也不得把事件视为每位成员已成功切服的确认。队伍在事件投递前被取消时不会投递；成员执行时仍会重新检查在线和队伍关系。
